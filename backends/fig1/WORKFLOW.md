# cell_cns_fig1

开场和结尾必须显示合并入口 `SKILL.md` 的固定提示；本分支的简短显示规则不省略这两处提示。
文字或图片 → 固定接口 → 独立 Python 等待 → SVG 返回 → 原聊天继续 → 可编辑SVG / 按需导入Adobe Illustrator。

## 输入与显示

- 支持文字、图片或图文一起，至少提供一项；都没有时只问“请发文字或图片。”不提交、不扣费。图片为真实 PNG/JPG，最大10 MiB；PDF先按用户选定页转成图片。保留用户原文，未提供的输入留空。
- 默认直接返回可编辑SVG（application=svg）。用户选择导入Adobe Illustrator时使用application=ai；只有这种明确选择才打开Illustrator，不要求预先新建文档。
- 每个新任务成功接收一次扣20额度；轮询、下载、SVG交付和导入不再次收费。提交前查询真实可用额度；已经明确授权本图20额度时不重复确认，否则只问“本次20额度，继续吗？”
- 接口写死在脚本中，没有地址配置或切换入口。只使用客户 API Key，不能使用后台接单或管理员密钥。
- 正常运行时，进度消息只能是“正在第1步。”至“正在第5步。”，不附步骤名称、解释、计划、技术细节或统计。只在进入新步骤时提示一次；等待期间没有变化不重复刷屏。任务ID、端点、路径协议、哈希、轮询日志和JSON留在后台；不要显示接口地址和密钥。
- 步骤固定：第1步准备输入和选择；第2步提交；第3步后台等待；第4步检查收到的SVG；第5步保存交付。后台返回原聊天后从第4步继续，不重新显示第1至3步。共享资源占用时保持当前步骤。
- 必要的缺图、选择、API Key、20额度确认和真实错误允许一句简短提示；不得用步骤提示掩盖失败。最终显示“完成。”和所选文件链接，并追加入口规定的结尾提示。预览、剩余额度和过程详情仅在用户需要时附上；最终返回SVG链接。
- 接收可编辑SVG后直接交付，按用户选择导入Illustrator。不执行图像识别、去字、去水印、原生对象重绘或额外付费接口。

## 提交并结束当前轮

使用本机已安装的 Python（例如命令 `python`）。调用与恢复命令见[客户端运行](references/client.md)。

1. 显示“正在第1步。”，保存提供的原图；提供的文字写UTF-8文件。给任务选择独立目录，记录当前真实`CODEX_THREAD_ID`，禁止猜聊天ID、另建聊天或发到姐妹聊天。
2. 核对选择与20额度授权，运行`client.py probe`确认桌面原聊天可达。先执行`discover-key`本地检测已有 API Key，再用`balance`查看实时余额。已有配置直接复用，只有明确未找到时才问“请提供小描 API Key。”；用户可在聊天提供，通过stdin交给`configure-key`，不复述或写到命令行。凭据只存当前Windows用户DPAPI密文；本机已有客户凭据可直接使用，不替换账号。
3. 显示“正在第2步。”，执行`submit --application svg|ai --job-dir ... --credits-approved 20 --authorize-wake`，有图加`--image`，有文字加`--text-file`，至少提供一项。调用者传入当前真实thread-id。启用本Skill处理该任务包含用户要求的“结果返回后通知原聊天继续处理”授权；不得扩大到别的聊天。
4. 脚本持久化原图与请求ID，注册登录/崩溃恢复，提交后自动启动独立Python等待进程。确认返回`charged_credits=20`且`background_waiter_verified=true`；仅回复“正在第3步。”并结束本轮。
提交后脚本自动在原聊天右侧创建并打开本地进度面板，返回`progress_opened=true`；无需模型另行打开。面板按1小时预估自动推进，结果未保存校验前最多99%；接收器已保存并校验SVG才到100%。等待期间结束模型轮次，让后台Python继续；不要为更新进度反复调用模型、发送聊天消息或轮询网站。面板未启动时仅运行`client.py progress --job-dir <原目录>`恢复，不重新提交订单。

5. 响应丢失只恢复原目录、原请求ID；不能换目录重新提交、重复付费。接收进程在后台检查原任务，收到SVG后下载、校验并保留，再通过桌面工具通知原聊天。原聊天正忙则等待空闲。

仅创建/更新/安装本Skill时不上传图片、不查询客户业务余额、不创建付费测试订单。可以做隔离本地测试和只读桌面连接检查。

## 结果返回后

1. 先读回执中的原任务目录与job.json，核对当前聊天就是记录的原聊天。执行`client.py acknowledge --job-dir ... --nonce ...`确认接收；不会再次发送订单。
2. 结果未通过SVG校验或回执是需要处理的状态时，报告实际原因并保留原任务，不把错误当完成，不重新收费。共享资源暂时占用时等待后继续。
3. SVG有效时执行 `client.py export --job-dir ...`，保留原件并生成可直接打开的SVG交付副本。详见 [SVG交付与导入](references/postprocess.md)。
4. 查看SVG实际预览，检查位置、比例、裁剪、箭头和文字；保留原图中的可编辑路径与效果，不执行PPTX转换或逐路径重绘。
5. 仅用户选定Adobe Illustrator导入（application=ai）时执行 `client.py import-illustrator --job-dir ...`；打开SVG独立文档，不修改已有文档。无法导入时提供SVG和实际原因，保留任务供恢复，不重新收费。
6. 验收完成且用户要求的导入已成功时执行 `client.py complete --job-dir ... --visual-checked`。最终返回SVG链接，并追加入口规定的结尾提示。

## 恢复边界

无窗口Python接收器持续等待，登录时直接启动的pythonw常驻监控器负责恢复；不周期性启动PowerShell或控制台，不创建Codex定时唤醒、不在聊天长时间sleep。重启后需登录当前Windows账号并让Codex桌面可用；密钥失效、显式停止或72小时本地等待超时会通知原聊天，不声称远端已取消或退款。正常无变化保持安静。

唤醒响应不明时保存`wake_uncertain`，先检查原聊天回执，不盲目重复发送；读取本地原结果后可在原聊天继续acknowledge/export。用户明确停止时执行stop，保留原图、已返回SVG和远端订单；恢复沿用原任务。
