# 原路径直接绘制

1号、2号统一使用本 Skill 内置的路径解析、PPT 写入与 Illustrator COM/JSX。运行时不调用其他 Skill，不重新识别或重绘素材。

## 固定位置和大小

保留服务端 result.svg 原件及哈希，在任务目录生成转换副本。按原路径 d、坐标、尺寸、父级 transform、嵌套 SVG 的 x/y、width/height、viewBox 和 preserveAspectRatio 直接绘制，保持原先叠放顺序与复合子路径。不自主排版、不重新调整素材大小、不合并或剔除重叠路径。局部 use 引用在原位置展开，重复实例分别保留。

## 效果不拦截

不设置“转换器不支持效果就停止、要求兼容处理后才能交付”的额外要求。嵌套 SVG 的视口裁剪必须按下文的坐标规则自动求可见路径交集，属于几何转换，不能删除视口边界来绕过。其他效果沿用直接路径映射：线性/径向渐变取首个色标；显式 clip-path、蒙版、滤镜按当前映射规则简化；虚线沿原路径映射；普通文字保留可编辑。效果简化只发生在副本，记录在 direct-mapping.json，不重新提交收费任务，也不要求用户确认。不能将这种映射称为原 SVG 所有效果的无损复现。

旧任务出现“无法处理嵌套素材裁剪”时，使用本 Skill 当前内置转换器，沿用已接收的原 SVG，在新输出目录重建转换副本与几何缓存，再继续 convert 和 complete。不能复用旧版不兼容缓存，也不能仅报告这一兼容性提示就结束。保留原件与旧输出，不重新生成科研图、不创建收费订单。只有实际生成并检查所选 PPT/AI 后才能报告完成；其他真实执行错误仍须处理或如实报告。

## 输出

PPT 使用内置几何缓存和 OOXML 原生形状、文本框写入，跳过隐藏/重叠路径剔除。AI 使用内置 COM/JSX 原生路径写入，保存 AI 并导出 PNG；沿用原任务选定的目标文档。软件或文档未打开、输入损坏、文件写入失败等真实执行错误仍需解决，不能假报完成。

模式 bundled-direct-v6 使用新的输出目录，保留旧文件。原 SVG、映射哈希与输出哈希一致时复用结果；旧转换模式先沿用原 SVG 本地重转。实际预览检查素材位置、比例、叠放和箭头，不因渐变等效果差异拦截交付。

## 字体

默认使用 **Times New Roman（新罗马体）**。用户另行指定字体时，以用户要求为准。提交任务时用 `submit --font "字体名"` 保存用户选择；已有任务用 `convert --font "字体名"` 修改。未指定时不要询问字体，直接用默认值。转换统一设置可编辑文字字体，保持原字号、位置和样式；路径轮廓文字按原路径保留。更换字体生成新转换目录，避免复用旧字体缓存。

## 坐标计算细节

先解析素材所在 SVG 的百分比尺寸与 viewBox，依次组合父级矩阵，得到全图坐标，再按整图统一比例转换为 PPT 点/EMU；Illustrator 使用同样的全图坐标并换算 Y 轴方向。素材内部路径超过其 SVG 视口时，自动求可见路径交集，保持贝塞尔曲线与原位置，不拉伸、不平移素材来掩盖越界。这是几何转换的一部分，不增加用户确认或效果兼容停止步骤。

零宽描边不绘制；填色路径即使未显式写 Z 也按 SVG 的隐式闭合填充处理。仅有 moveTo 的空路径跳过，不能画出错误连线。透明且零描边的素材边框不产生可见黑框。实际预览要检查这些情况，不能只凭文件能打开就判断正确。
