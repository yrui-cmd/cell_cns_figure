# 原路径直接绘制

1号、2号统一使用本 Skill 内置的路径解析、PPT 写入与 Illustrator COM/JSX。运行时不调用其他 Skill，不重新识别或重绘素材。

## 固定位置和大小

保留服务端 result.svg 原件及哈希，在任务目录生成转换副本。按原路径 d、坐标、尺寸、父级 transform、嵌套 SVG 的 x/y、width/height、viewBox 和 preserveAspectRatio 直接绘制，保持原先叠放顺序与复合子路径。不自主排版、不重新调整素材大小、不合并或剔除重叠路径。局部 use 引用在原位置展开，重复实例分别保留。

## 效果不拦截

不设置“转换器不支持效果就停止、要求兼容处理后才能交付”的额外要求。沿用直接路径映射：线性/径向渐变取首个色标；裁剪、蒙版、滤镜不参与几何映射；虚线沿原路径映射；普通文字保留可编辑。效果简化只发生在副本，记录在 direct-mapping.json，不重新提交收费任务，也不要求用户确认。不能将这种映射称为原 SVG 所有效果的无损复现。

## 输出

PPT 使用内置几何缓存和 OOXML 原生形状、文本框写入，跳过隐藏/重叠路径剔除。AI 使用内置 COM/JSX 原生路径写入，保存 AI 并导出 PNG；沿用原任务选定的目标文档。软件或文档未打开、输入损坏、文件写入失败等真实执行错误仍需解决，不能假报完成。

模式 bundled-direct-v4 使用新的输出目录，保留旧文件。原 SVG、映射哈希与输出哈希一致时复用结果；旧转换模式先沿用原 SVG 本地重转。实际预览检查素材位置、比例、叠放和箭头，不因渐变等效果差异拦截交付。
