# cell_cns_figure

把科研文字或参考图制作成可编辑的 **SVG 文件**，也可选择直接导入 **Adobe Illustrator**。

| 方案 | 建议 |
| --- | --- |
| **1号** | **日常使用选1即可**，支持文字、图片或图文一起 |
| **2号** | **适合高嵌套文件，更注重美观**，支持文字、图片或图文一起 |

使用时选择1号或2号，完成后领取SVG；需要时可选择导入Adobe Illustrator。

**仅2号（Pro）需要一次性邀请码**，生成后24小时内有效。1号不需要邀请码。
