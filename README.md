# cell_cns_figure

把科研文字或参考图制作成可编辑的 **PPT 或 Adobe Illustrator 文件**。

| 方案 | 消费 | 建议 |
| --- | --- | --- |
| **1号** | **20额度/任务** | **日常使用选1即可**，支持文字、图片或图文一起 |
| **2号** | **45额度/任务** | **适合高嵌套文件，更注重美观**，支持文字、图片或图文一起 |

使用时选择1号或2号，再选择PPT或AI，完成后领取文件。

每个新任务成功接收时扣费一次，结果接收和文件转换不重复收费。

**仅2号（Pro）需要一次性邀请码**，如 `Cell_Projkldjd`。使用一次即失效，余额不足也失效；余额不足不扣费、不创建任务。邀请码不抵扣费用，成功接单仍扣45额度。1号不需要邀请码。

邀请码自生成时起24小时过期，以服务器时间为准；过期后不能提交，须取得新码。重新查询或重复签发旧码不会延长有效期。已受理订单的等待、接收和转换不受邀请码到期影响。
